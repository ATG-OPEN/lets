# Security policy

## Supported versions

Fixes are made on `main` and in the latest release.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub:
**Security → Report a vulnerability** on this repository
(<https://github.com/ATG-OPEN/lets/security/advisories/new>).

Include what is affected (file, function), how to reproduce it, and the impact you expect. You
will get an answer within a week; once a fix is ready, it is released and the advisory is
published with credit to you, unless you prefer otherwise.
